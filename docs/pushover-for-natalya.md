# Phone notices for Private Photos

This sets up a small app called Pushover so your iPhone can tell you when Dave sends a chat message on Private Photos. The notice shows the start of his message. You can tap it to open the chat.

You only need your own Pushover account. You do not create an app, and you do not need an API token. Dave already has the part that sends the notices.

Pushover is free for 30 days. After that, the iPhone app asks for a one-time purchase, currently $4.99, called **Pushover License**. There is no monthly fee.

## 1. Install Pushover

1. On your iPhone, open the App Store.
2. Search for **Pushover**.
3. Install **Pushover Notifications** by Pushover, LLC.
4. Open the app.
5. When the iPhone asks to allow notifications, tap **Allow**. If you tap Don’t Allow, the notices will not appear.

## 2. Create the account

The app walks you through this the first time you open it.

1. Create an account with an email address you can open, and a password you will remember.
2. Finish whatever confirmation Pushover asks for. Check that email if it sends a link.
3. Stay logged in on the iPhone. That registers this phone to receive notices.

Use the same email and password if you also open [https://pushover.net](https://pushover.net) on a computer.

## 3. Copy your user key

Your user key is a long code of about 30 letters and numbers, with no spaces. It is not your password. Pushover also emails it to you when the account is created.

On the iPhone:

1. Open Pushover.
2. Open **Settings**.
3. Find **User Key**.
4. Copy it.

On a computer, the same code is on your dashboard after you sign in at [https://pushover.net](https://pushover.net). It is in the upper right.

## 4. Send the user key to Dave

Send Dave only that user key, in a text or an email. Copy and paste it so no letter is missing.

Send him:

- the user key

Do not send:

- your Pushover password
- an API token or application token, if the website offers to create one

Anyone who has the user key can ask Pushover to notify your phone, so send it only to Dave. Do not post it on a website or in a group chat.

## 5. What you should see

After Dave adds the key, send him a short chat message from Private Photos, or ask him to send you one.

You should get a notice titled **Private Photos**. The text starts with **Dave:** and the beginning of his message. Tap **Open chat** to go to the conversation.

Your own messages do not notify your phone. A message from you notifies Dave.

## If a notice does not arrive

- In the iPhone Settings app, open **Notifications**, then **Pushover**, and turn **Allow Notifications** on.
- Open the Pushover app once so the phone is registered. On the website dashboard, this iPhone should be listed under your devices.
- On the Pushover website, use **Send Notification** on your dashboard to send yourself a test. If that test does not arrive, the iPhone setup still needs a fix. If the test arrives but Dave’s chat does not, send him the user key again and ask him to check that he saved it.
- Quiet Hours inside Pushover can hold notices. Leave those off unless you want them.
